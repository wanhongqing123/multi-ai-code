# OpenCV 图片分析工具

九个工具在 MaiAgent 中定义相同的协议，MaiChat 各端用同一份 OpenCV 实现注册：

| 工具 | 输入 | 输出 | 适合做什么 |
|---|---|---|---|
| `cv_image_quality` | 一张图片 | 清晰度方差、亮度、对比度、暗部/高光占比 | 比较相似照片，筛掉明显失焦或过曝素材 |
| `cv_image_compare` | 两张同尺寸图片 | 像素差、变化占比、PSNR、dHash 距离 | 判断处理前后是否真的变化、查找近似重复图 |
| `cv_find_contours` | 一张图片 | 按面积排序的外轮廓矩形 | 找几何区域，供后续裁切或检查边缘 |
| `cv_detect_edges` | 一张图片 | 新的灰度 Canny 边缘图 PNG | 检查主体轮廓或处理边界 |
| `cv_match_template` | 原图＋局部小图 | 匹配框与分数 | 在截图或画面中找同尺度的已知元素 |
| `cv_register_translation` | 两张同尺寸图片 | 水平／垂直平移量及响应值 | 对比两帧前先估计相机平移 |
| `cv_detect_lines` | 一张图片 | 线段与近水平倾斜角 | 判断扫描件、地平线或建筑线条是否歪斜 |
| `cv_document_corners` | 一张图片 | 最大文档四角 | 为后续透视校正提供坐标；不直接重编码原图 |
| `cv_threshold_mask` | 一张图片 | 新的黑白 PNG 蒙版 | 给扫描件、图案或后续合成制作二值蒙版 |

输入只能是 Agent 可访问的本地文件，原图不修改；边缘图只能写入 Agent 工作区的新
PNG 文件。解码由当前宿主编译的 OpenCV 图片编解码器决定，不支持时应先用 FFmpeg
转成 JPEG/PNG。输入文件上限 30 MB，解码后上限 2400 万像素。质量测量统一缩到
最长边 1024 像素再计算，清晰度方差适合比较相似素材，不是跨场景通用的“好照片”
判定阈值。两图比较要求尺寸一致，不偷偷缩放或配准。

OpenCV 的这条路径不做 ICC/HDR 色彩管理，`cv_image_compare` 的数值不能用来验收
P3/HDR 色彩保真。轮廓是几何边界，不是语义识物。真正的主体识别要用已接入的
人脸/人物模型或视觉大模型。简单裁切、旋转、缩放与滤镜继续用现有 FFmpeg，避免
重复造一套处理链。

模板匹配按原像素尺度定位，缩放、旋转和透视改变后的图片应先配准；得分不等于
“语义上是同一个东西”。模板匹配上限为 1200 万源像素；平移配准两图同尺寸，
上限为 400 万像素，只估计 x/y 位移，不执行像素重采样。文档四角只在
边框足够清晰时返回 `found=true`。蒙版输出是单通道灰度 PNG，不承诺保留原彩色图
的 ICC/P3 信息。

验证：Mac Desktop 的 `MaiCvImageAnalysisTests` 用合成图真实调用 OpenCV，覆盖质量
数值、相同/不同图片的差异、轮廓坐标、模板位置、平移量、线条与倾斜角、文档四角，
以及可解码的边缘图和二值蒙版；MaiAgent 的
`MaiCvImageToolsTests` 检查路径边界和参数限制。移动端编译后还需真机功能验收。
