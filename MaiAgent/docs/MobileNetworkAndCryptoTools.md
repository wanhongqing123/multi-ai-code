# 移动端网络、压缩与密码学工具

这些能力通过同一份 MaiAgent 工具清单提供给模型。iOS 不执行本地命令行程序；
HTTP、zlib、OpenSSL 和 SSH 的执行逻辑都在共享 C++ 工具中。SSH 的密码输入与
首次主机指纹确认由各端界面负责。

| 工具 | 用途 | 主要边界 |
|---|---|---|
| `ssh_exec` | 连接云主机并执行一条远程命令 | iOS/Android/Mac/PC 共享 libssh2 实现；同一 AI 会话内可复用十分钟内的已认证连接；账号密码在本机弹窗输入；首次连接核对 SHA-256 主机指纹；每条命令单独确认；标准输出和错误输出各最多 48 KiB；超时最多 120 秒 |
| `curl_request` | 调用 HTTP(S) API，取状态码、常用响应头、正文、耗时 | GET/HEAD/POST/PUT/PATCH/DELETE；每次调用确认；请求正文最多 256 KiB，响应最多 256 KiB；不自动跟随重定向；不接受 URL 内嵌用户名或密码 |
| `curl_upload` | 将工作区文件流式上传到 HTTP(S) 地址 | 原始 PUT/POST 请求体，不是 multipart；文件最多 1 GiB（默认上限 100 MiB）；每次调用确认；不跟随重定向，源文件不变 |
| `zlib_compress` / `zlib_decompress` | gzip、zlib、raw deflate 文件互转 | 输入最多 16 MiB，解压输出最多 64 MiB；新建文件，不覆盖原文件；支持自动识别 gzip/zlib |
| `crypto_digest` | 计算文件或文本的 SHA-256、SHA-512、SHA3-256、BLAKE2b-512、MD5 摘要 | 文件最多 64 MiB；MD5 仅供旧文件校验，不用于安全判断 |
| `crypto_certificate_info` | 读取 PEM/DER X.509 证书的主体、签发者、有效期、公钥和指纹 | 本地文件最多 1 MiB；只读，不发网络请求 |
| `mobile_save_video` | 把工作区 MP4/MOV/M4V 加入系统相册 | iOS/Android；视频轨道校验；文件最多 2 GiB；原文件不变 |

`ssh_exec` 的密码没有工具参数，不会写入模型上下文或聊天记录。首次连接时
弹窗给出服务器公钥的 SHA-256 指纹，用户应与云主机控制台核对；已信任服务器的指纹
发生变化时会拒绝连接。复用连接时不重复登录，但每条命令仍在新的 SSH channel 中
独立执行，`cd` 等 shell 状态不会延续。连接只保存在 App 进程内，空闲超过十分钟
或出错后下一次调用会重新登录；iOS 后台挂起和网络切换也可能使连接失效。
它不是交互终端，也不提供私钥登录（当前需求先做账号密码）。

通用网络能力由 `MaiCurlTools.cpp` 注册为一个 `curl` 模型工具，复用仓库内 curl
8.11.1 的内嵌命令入口。网页提取、下载、短请求和原始文件上传按参数处理，
旧实现留作内部类型化入口，不再重复暴露给模型。TLS 验证保持开启。上传目标应提供用户明确
认可的地址；签名 URL 会写入工具调用记录，不能把长期口令放在 URL 或工具参数中。

zlib 1.3.2 完整源码与 OpenSSL 3.5.9 LTS 的运行所需源码位于 `third_party/`。
OpenSSL 的上游示例私钥、测试和演示目录不入库；移动端与 macOS 离线构建内嵌
`openssl` CLI，只开放只读的 `version`、受限 `dgst` 和 `x509`。Windows 暂使用
从同一源码构建的 libcrypto 与原有类型化摘要、证书工具。不把私钥或对称密钥作为
模型工具参数。

AI 助手的“正在思考／已思考”是客户端中文文案。展开后的思考文字是模型原文；
系统指令会要求中文用户的可见推理使用简体中文，但服务端模型仍可能返回英文。
客户端不会伪装成模型原文进行异步机器翻译。
