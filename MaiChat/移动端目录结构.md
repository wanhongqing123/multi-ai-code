# 移动端源码目录

iOS 应用源码在 `ios/MaiChat/MaiChat/`，按 App、Assistant、Chat、Contacts、Diagnostics、IM、RemoteDesktop、Settings、Speech 分目录。`MaiChatTools/` 与这些功能目录并列，放 MaiChat 提供给 MaiAgent 的跨功能宿主工具；其中 Swift 文件由 Xcode 编译，`MaiMobilePhotoAlbumTool.cpp` 由共享移动端 CMake 编译，XcodeGen 配置排除该 C++ 文件。可复用的代码在 `ios/MaiChat/MaiChatCore/` 中按对应功能分目录，助手路径策略与文本解码也在那里独立测试。

Android 应用源码仍从 `android/MaiChat/app/src/main/` 进入。Java 在 `java/` 下按对应功能分目录，各功能目录在 Gradle 中声明为 source root；目录内保持 `com/kongshang/maichat` 包路径，因此现有包名和包内可见性不变。宿主工具单列于 `java/MaiChatTools/com/kongshang/maichat/tools/`。原生代码位于 `cpp/`，`cpp/MaiChatTools/` 放 Android 专用的相簿工具实现。

两端共用的宿主工具注册和图片滤镜放在外层 `MaiChat/MaiChatTools/`；移动端 Agent 桥接、媒体依赖构建、模型资源和适配器测试放在 `MaiChat/MobileAgentAdapter/`。
