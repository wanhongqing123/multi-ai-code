# MaiChat 账号与好友关系验收清单（2026-10-18）

本清单记录用户确认的目标行为。当前腾讯 IM 好友关系为主、账号服务按小时复制好友镜像的实现，不符合目标；实现时逐项更新状态，不把现状当作验收结果。

## 账号与身份

- [ ] 手机号是可选的登录和精确查找方式，不是好友关系主键。无手机号测试账号可正常使用。
- [ ] MaiChat ID 是稳定的账号及好友身份。新普通账号使用短 ID，避免现有 36 字符 UUID；既有账号的 ID、会话、绑定和好友数据安全迁移。
- [ ] 普通账号的腾讯 IM ID 单独映射到 MaiChat ID。测试账号由管理员填写 MaiChat ID，腾讯 IM ID 与所填 ID 相同；更换 IM 服务时允许重建测试账号。
- [ ] App 的“账号”、复制账号和分享二维码均指 MaiChat ID；腾讯 IM ID 不再冒充用户账号。

## 管理员与登录

- [ ] 受保护的管理员界面可创建、查看及停用测试账号。管理员自行填写唯一的 MaiChat ID 和密码；手机号可留空。校验腾讯 IM ID 格式，密码只保存慢哈希，不在日志或界面回显。
- [ ] iOS、Android、macOS、Windows 均支持 MaiChat 账号＋密码登录；现有手机号验证码和手机号密码登录继续可用。
- [ ] 测试账号能通过账号＋密码在目标平台登录，获得自己的 MaiChat 会话和当前 IM 凭据；停用后会话失效。

## 好友关系与入口

- [ ] MaiChat 账号服务维护申请、同意、拒绝、删除及已接受好友列表，关系以双方 MaiChat ID 表示；跨平台读取同一份关系。
- [ ] 手机号、MaiChat ID、好友二维码都解析为同一 MaiChat 账号；申请、审批路径一致，不能通过输入任意腾讯 IM ID 绕开 MaiChat 关系。
- [ ] 接受好友后把关系同步到腾讯 IM；失败应保留可重试状态并对账，不把 IM 关系定时复制为 MaiChat 主关系。
- [ ] 本地通讯录缓存与聊天历史分开；删除好友后四端列表都不再把该用户显示为好友，聊天记录不因此丢失。
- [ ] 各平台的普通代码入口与模型工具入口复用同一业务操作，不允许工具直接绕过申请或审批。

## 交付

- [ ] 服务端通过无手机号账号、登录安全、双账号申请/审批/删除、IM 同步失败恢复和旧账号迁移测试。
- [ ] iOS 模拟器、可用 iOS 真机、Android 模拟器及 Android 真机、macOS 与 Windows 在实际构建上验证账号登录和双方好友流程；无法访问的平台如实记录。
- [ ] 服务代码重新部署到现有云服务器，核对运行版本、健康状态、未登录拒绝、管理员入口保护及有效账号流程。
- [ ] 不替换仍在执行其他任务的已安装 App；发布资产与真实安装状态分别记录。
