# MaiChat iOS 群聊首版（2026-10-24）

## 用户流程

消息页右上角“＋”展开三项：发起群聊、添加朋友、扫一扫。发起群聊从已接受好友中选择 1–19 人、填写不超过 30 个字的群名；创建成功进入群详情。扫一扫只识别 MaiChat 好友二维码，识别后填入现有好友申请框，由用户确认发送。

群聊首版支持文字消息：会话列表显示群名、成员数、最近消息和未读数；详情页可发送文字、接收成员消息和继续加载历史。媒体、语音及远程桌面等私聊功能不在群详情中显示。联系人分组和群发均不充当群聊。腾讯 IM 的 [Work 群](https://trtc.io/document/48466?product=chat)作为后端，不新建聊天消息代理服务。

## 状态与失败处理

- SDK 使用真实群 ID；群消息在进入 C2C 路径前分流。核心状态用显式会话类型和群 ID 索引，SQLite schema10 的 `group_id` 区分群/私聊；旧私聊行保留，旧库逐列迁移。
- 新建 Work 群后等待一条隐藏的内部激活消息成功发送，才返回“创建成功”；该消息不计入未读和最近消息。若群已创建而激活失败，持久化待恢复状态，重启后仍提供“打开已创建群聊”，阻止再次建重复群；用户发送首条群文字后清除待恢复状态。
- 退群、被移出群或切换账号时，当前群详情与旧群消息立即退出视图。群历史分页使用腾讯 SDK 的原始消息游标，避免一页全是非文字消息时误判结束。

## 已验证与边界

- iPhone Air iOS 26.4 模拟器：建群、群文字、模拟成员回复、切回私聊不串消息 2/2；退群与切账号 UI 回归 2/2；加好友与扫码流程 3/3；原私聊导航和长历史 2/2。核心/SQLite 测试覆盖旧库迁移、账号隔离、群/私聊分流、回显、分页及重启恢复。
- iOS Release 2.2.3(117) 已签名并安装到 iPhone 14 Pro Max；设备安装列表回读版本 117。手机锁屏时系统拒绝远程启动，故真机运行和真实相机扫码尚未验收。
- 模拟器群成员和回复来自仅模拟器启用的假数据；真实腾讯 IM 双账号邀请、激活、发送、收取与跨端显示尚未验收。当前 Desktop/Android 没有群聊界面，不能把 iOS 首版表述为三端群聊对齐。腾讯 SDK 本地 `findMessages` 游标在本地缓存被清理后可能失效，届时需从最新页重新同步。
