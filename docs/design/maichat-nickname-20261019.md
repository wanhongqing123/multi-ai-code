# MaiChat 昵称验收清单（2026-10-19）

用户确认：个人资料中的“名字”改为“昵称”；MaiChat 账号昵称是唯一主数据。腾讯 IM 昵称并非登录或加好友的前提，只接收 MaiChat 昵称的同步。昵称为空时显示 MaiChat ID，不维护第二套可编辑名字。沿用账号与好友功能的跨平台要求。

## 账号服务

- [ ] `users` 增加可空昵称；现有手机号账号、无手机号测试账号、会话和好友关系无损迁移。
- [ ] 已登录用户可读取、修改和清空自己的昵称；未登录拒绝修改，输入长度和控制字符受限。
- [ ] 登录、刷新、`auth/me`、好友查找、申请和好友列表返回同一昵称；未设置时由客户端显示 MaiChat ID。
- [ ] 修改后把相同昵称投影到腾讯 IM，失败保留可重试任务，较新的修改不被旧任务覆盖；服务端重启后继续同步。
- [ ] 后台服务重新部署；线上只读核对健康、鉴权、有效账号和同步状态。

## App

- [ ] iOS 个人资料把“名字”改为“昵称”，提供修改入口；“我”、聊天和好友展示优先使用 MaiChat 昵称。
- [ ] Android、macOS、Windows 的资料、好友和聊天展示同一昵称，并提供普通 UI 修改入口。
- [ ] 账号 ID、腾讯 IM ID、好友关系和聊天历史不因改昵称变化；普通代码入口与模型工具入口复用同一账号资料操作。
- [ ] 在实际目标构建和可用设备上验证设置、清空、重启、双账号看到对方昵称，以及同步失败后的恢复；明确未验收的平台。
