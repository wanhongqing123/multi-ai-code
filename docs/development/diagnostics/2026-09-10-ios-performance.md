## 本轮改动

- ASR 阶段绑定手势开始时冻结的账号、peer 和随机 asr_session；识别器沿用同一上下文，远程报告保留阶段元数据，不含正文、录音、密钥。
- 补充 stop_wait_ms、stop-timeout-fallback、SDK stop 调用耗时和文字应用耗时；失败仅输出错误码。
- 空闲 cancel 不再无条件排队 setActive(false)，避免每次 start 前多做一次音频停用；实际活动或准备中的会话仍清理。
- session-started 拆分 audio_queue_ms、audio_category_ms、audio_activate_ms、audio_resume_ms。总 audio_session_ms 保留。
- 接入 SDK flow-started、recording-stopped 回调，补充 callback_latency_ms 与 main_actor_wait_ms。flow-started 只是 SDK 阶段回调，不等同于原始网络包时间。
- 音频分片、VAD、网络配置保持现有值，未提前录音或让麦克风持续常开。
