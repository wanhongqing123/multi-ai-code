# 跨端远程排障（实现中，尚未发布）

## 用户流程

- A 是 iOS 或 Desktop MaiChat，正在与 B（远端 MultiAICode 好友）聊天。
- 在当前聊天打开“远程排障”，选择接收报告的好友 C（如 mac-multi-ai-code / house-multi-ai-code），确认采集与发送。
- 不要求用户先判断问题类型，不要求到 B 的机器寻找文件，也不要求另行拼接多个日志。
- A 收集本地收发/展示元数据，并请求 B 的宿主采集关联现场。B 只向已授权的请求者 A 回传；A 整理为同一报告后发送给用户选定的 C。
- 收集状态、缺失项及原因可见。B 离线、旧版本不支持、超时、日志已轮转、部分采集失败都不能伪装成完整成功。

## 一份报告的最小内容

- 同一排障编号、A/B 端身份、各端时区和时间范围；时间不一致必须保留，不强行合并为准确因果顺序。
- A 的应用版本、收发消息 ID/状态、展示相关事件；不默认导出无关会话正文。
- B 的 MultiAICode 运行版本、进程启动时间、相关 AICLI 进程/内核来源提交；区分磁盘已更新与运行进程仍旧。
- 关联的 session/task/reply/message/part/turn ID，路由建立/拒收/跳过/转发及 SDK 发送结果。
- 对应 AICLI 原始事件的元数据（item 类型、phase、delivery、call ID、完成状态）。本次异步提问正是在进入 IM 链路之前丢失，只收 IM 日志不足以定位这一类问题。
- 已采集/缺失/截断的清单；没有日志不能推导为没有故障。

## 安全与实现边界

- 采集命令由 MultiAICode 宿主直接处理，不能依赖 AI 当前轮、taskId 回复路由或 AI 自己决定导出什么。
- 校验好友权限、当前账号/连接代次、请求编号及超时；重复请求需幂等/限流，不能无限生成报告。
- 只接受固定、限时、限量的采集范围，不接受任意文件路径、shell 命令或由 B 指定的第三方收件人。
- 报告先回到 A，再由 A 根据本次明确选择发送给 C；不得自动广播给所有排障好友。
- 凭据、认证配置、环境变量、无关会话正文不进入报告；日志新增未知字段不能自动被透传。
- 不修改配置，不重启/清空 AICLI，不改变当前工作任务，不自动补发旧回复。
- 首次需要升级 A 与 B。旧客户端明确提示不支持；发布资产与源码实现状态分开报告。

## 当前状态

宿主与 iOS 初版已接线，尚未发布；Desktop 由独立分支实现，待合入联调。

- 宿主：`/diagnostics <小写 UUID>` 走已有 human-origin + 好友授权控制入口，直接生成 JSON 附件，不调用 AI。请求在聊天中可见，由按钮自动生成，不要求用户手输。
- 附件：`remote-diagnostics-<UUID>.json`，`schemaVersion=1`，文件名与 JSON 的 `requestId` 均须匹配。只回传给请求者，不接受第三方收件人或文件路径参数。
- 采集：当前项目最近 30 分钟，源读取有字节、条数、目录与文件数量上限；原始事件仅支持应用专用 Codex home 中匹配当前项目的 rollout。其他 CLI 仍有宿主日志/生命周期，原始事件明确为 `unavailable`。
- 运行信息：启动时记录的 sourceCommit/进程时间，与采集时磁盘文件的 SHA-256 分开标注，不把磁盘文件当作运行中映像的证明。
- 临时报告：25 秒采集上限；重复请求复用结果并限流；应用报告缓存最多 64 份，清理其中超过 24 小时的生成文件，不清理原始日志。
- iOS：更多菜单、选择 C 后确认、60 秒等待、源身份/编号/2MiB 校验、未知字段过滤、合并并定向发送。取消、账号或好友失效不继续回传；已开始的网络发送不能撤回。
- iOS 本地报告含近期消息 ID/方向/状态和本次启动保留的收发/视图挂载元数据。视图挂载不等于屏幕像素绘制；不存在的历史记录不补造。
- iOS 文件下载开始时绑定 SDK 账号与报告编号；旧账号完成的下载不能在新账号入库。报告编号只从完整匹配的固定文件名提取，不导出下载 URL、文件路径或原始错误文本。
- 本次报告附件的下载失败会提前结束等待并发送部分报告；其他好友或其他编号的失败不触发。合并时保留请求前的消息快照，并补入等待期间的账号限定下载记录。没有明确证据时只写“未收到有效报告”，发送回调超时只写“发送结果未确认”。
- iOS 功能测试通过，应用编译通过；视觉检查使用独立的无 SDK/无登录配置模拟器预览程序，已查看实际截图。逻辑测试宿主不能可靠截图，未把空图当成视觉通过。真实腾讯 IM 跨机端到端仍待联调，不能把替身接口测试表述成实网验证。

`messageId` 必须保留 string 与 number 两种既有合法类型：数字是宿主本地入库编号，字符串是 AICLI 消息/调用 ID；大写 `ID` 是 `send:created.detail.ID` 中的 SDK 字符串。其他数字字段不能接受字符串伪装。`sourceCoverage.aicliOriginalEvents` 只接受 `see-codex-original-events` 与 `unavailable`。

## 验收要求

- 两种 MaiChat 均能发起并指定 C，取消后不采集/不发送。
- B 无运行中 AI、AI 正忙、普通回复路由失效时，宿主采集仍可执行。
- 未授权请求、跨账号过期响应、第三方重定向不能导出数据。
- 两端事件可通过同一排障编号及原始消息 ID 对照；异步提问只在 AICLI 原始事件出现时，报告能显示这一差异。
- 离线/旧版本/超时/缺失日志明确为部分报告；敏感信息哨兵及其他项目/会话哨兵不能出现在附件。
- 从实际发送入口捕获最终附件验证，不仅测试导出函数；iOS 与 Qt 的入口和转发行为均需验证。
