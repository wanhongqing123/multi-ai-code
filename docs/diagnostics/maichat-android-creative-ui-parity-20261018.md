# Android 创作中心底栏与键盘交互偏离 iOS（2026-10-18）

## 用户现场

- OPPO A3x 5G，Android 15，MaiChat 2.2.1 (221)。用户照片显示底栏有消息、创作中心、通讯录、远程、我五项，且图标位于独立圆角灰色外框内。
- 用户反馈：输入框唤起键盘后，点消息区空白处键盘不收起、输入区不回到原位；期望键盘发送键可直接发送。
- 拍照时当前会话有一项视频任务显示 `RUNNING`。在任务结束前不替换已安装 App，以免影响当前会话和任务观察。

## 对照与根因

- iOS `RootView.swift` 的 `CompactTabBar` 只有消息、创作中心、通讯录、我四项；白色底栏顶部是一条分隔线，没有 Android 的圆角灰色外框。远程桌面由聊天中的入口进入。
- Android `MainActivity.bottomTabBar()` 额外插入了 `REMOTE`，并为整个底栏和选中图标画了圆角背景。
- Android `AIAssistantPanel` 已有 `hideKeyboard()`，但消息列表空白点击没有调用它；触摸后输入焦点仍在编辑框，IME 视口不会恢复。
- iOS `ComposerTextView` 的 Return 是 Send；有草稿时另显示上箭头。用户确认按 iOS 当前行为对齐，因此 Android 保留条件显示的上箭头，同时把 IME 发送动作接到同一 `send()`。

## 修复与验收边界

- Android 底栏改为四项、白底加顶部细分隔线。远程桌面页签仍是内部导航状态，聊天中的远程入口保留。
- 消息区轻点时收起键盘并清除编辑焦点，保留未发送草稿；滚动不触发收键盘。键盘发送动作与上箭头调用同一发送路径。
- Android Java 与设备测试源码编译通过；需要从新提交构建同签名 2.2.2 包，在模拟器检查四项底栏、键盘动作、横竖屏，并待 OPPO 当前视频任务结束后实机复测。未执行这些视觉/真机步骤前不宣称 UI 验收完成。
