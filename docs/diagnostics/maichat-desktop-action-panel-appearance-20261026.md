# Desktop 创作中心更多菜单悬停底色断裂

- 时间与现场：2026-10-26，macOS 原生 Qt MaiChat。用户截图中，右上角菜单的“思考强度”行在悬停时仅两侧出现浅蓝色，中间留白；四项入口的层级和间距也显得拥挤。
- 复现基线：`d8470053cb1b489eac690b0ab4a6baa46e6ce6ce`。截图中该行的两侧是浅蓝色，横向中央保持纯白；代码位于 `MaiChat/desktop/src/agent/AgentChatPanel.cpp` 的 `agentActionPanel`。近期 `ff918121` 把菜单从 280 缩到 252、行高从 40 缩到 36，并移除外框。
- 定位判断：摘要行是 `QPushButton`，标题、当前值和箭头是铺在按钮上的三个 `QLabel`。按钮的 `:hover` 背景只在未被子控件覆盖的区域显露；子控件仅指定文字颜色，没有透明背景声明。截图的分段位置与子控件区域吻合，故按子控件遮住悬停底色处理。
- 修复：为摘要行的文字控件明确设置透明背景和无边框；将两项设置改为名称、当前值两级排列，恢复菜单边界和合理行高；为选项提供整行选中态，并把工作目录和清空当前对话整理为独立操作。Windows 编译时同时修正新共享网络源码里 `windows.h` 的 `min/max` 宏冲突，不改变网络行为。
- 验证：Windows VS2019 / Qt 5.15.2 Release 重链 `maichat`、`agent_panel_session_test`、`main_window_layout_test`。测试用例对摘要文字控件中央的悬停像素断言完整底色，折叠、展开与悬停截图已人工检查。Agent 测试 43/43，布局测试 145/145（另 1 项按条件跳过），隔离暂存版 `--smoke` 退出 0，日志版本 2.2.26、TLS 后端 OpenSSL。
- 边界：Mac 原生 Qt 画面尚未在 Windows 主机上直接运行，不能把 Windows 截图当成 Mac 实测。未安装或替换用户现用 MaiChat。
