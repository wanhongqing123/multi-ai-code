## 继续与重试边界

- `MaiResponsesClient::stream` 的 `inactive` 分支在自动重试判断前直接返回，**当前不会自动重试这种静默错误**。现有自动重试仅适用于尚未输出正文/推理/工具调用的暂时连接/收发错误、HTTP 408 或 5xx，默认最多 2 次。
- `MaiTurnRunner` 遇模型错误结束循环，不自动重放旧工具。原会话发送“继续刚才的代码审查，利用已读取的 diff 继续”可接着处理；`MaiContextBuilder` 按 call ID 回灌已存工具调用与结果。模型仍可能自行决定再次读文件，不能承诺绝无新工具调用。
