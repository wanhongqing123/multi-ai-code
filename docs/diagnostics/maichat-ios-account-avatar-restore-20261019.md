# iOS 已有账号的 ID 与头像恢复（2026-10-19）

## 现场

- iPhone 14 Pro Max 上原位安装 MaiChat 2.2.2(90) 后，用户在 09:53 的设置页看到“登录账号：未登录”；同页仍出现仅对本地账号会话开放的设置密码与扫码登录电脑入口。10:26 的“我”页账号文字为空。
- 用户刚设置新头像后将 App 退至后台，再进入时看到默认头像。没有卸载 App 或主动切换账号。
- 源码基线 `19361fda`，iOS 产品代码上次修改为 `a848a72b1`；安装版与该 iOS 产品代码一致。

## 根因证据

- `RemoteIMAppState.init` 从 Keychain 判断已有账号会话，并从本地设置恢复 SDK 连接所需的腾讯 IM ID；新增的 `maiChatAccountID` 默认仍为空。它只在 `finishAccountLogin` 的新登录路径赋值。`validateCurrentSession` 虽调用 `auth/me`，却丢弃了服务端返回的 MaiChat ID。设置页把这个空字段直接显示为“未登录”，头像旁的自我名称回退路径也因此得到空字符串。这是显示错误；单凭截图无法判断服务器会话是否有效。
- 新头像上传成功后，图片只保存在 `RemoteIMAvatarImageStore` 的内存 `NSCache`，自身头像 URL 没有写入本机账号快照。`image(for:)` 缓存未命中时直接回退默认图，前台恢复也不保证重试下载。系统回收缓存或重启进程后可出现用户所见现象。现场究竟是缓存回收还是进程重启，现有截图无法区分。

## 修复与验证

- 产品提交 `99e71ad7`：账号快照按 IM 账号隔离保存 MaiChat ID 与自身头像 URL，旧快照缺失新字段时安全解码；已有会话从 `auth/me` 校验 IM 身份后回填并落盘 MaiChat ID。无别名的本地账号态暂显示“MaiChat ID 待同步”，不再误报“未登录”。腾讯 IM ID 仍仅供 SDK 连接使用。
- 自身头像更新成功后立即保存 URL；图片内存缓存未命中时按 URL 请求，App 回到前台时重试并预取，IM 资料暂未返回头像 URL 时保留本机已确认的 URL。
- iOS 模拟器使用临时无手机号账号完成密码登录、终止 App、重新启动并进入设置页；同一 MaiChat ID 在重启前后均有截图，定向 UI 测试 1/1 通过。临时账号已停用，生产库只读核对活跃 QA 账号 0、完整性 `ok`。`npm run check:line-width` 与 `git diff --check` 通过。
- iPhone 真机 Release 构建和签名校验通过；包内主程序 SHA-256 `787855f4fd71ed2c33be6bd0bc1a92b6fb348b6f18374418736e63056fac4276`。同 Bundle ID 原位安装后，系统回读 MaiChat 2.2.2(90)，新安装路径下的进程启动成功。未卸载或清除 App 数据。
