# iOS Agent 相机自动拍摄排查记录

- 日期和平台：2026-10-30，iOS；开发基线 `f2709a861`。
- 需求：Agent 打开相机后约每两秒保存一帧，停止后在原会话选择图片；附件引用沙盒中的原图，不另存到相册或 screenshots。
- 验证方式：Debug 模拟器使用明确启用的合成相机画面，经过实际采样、归档、选图和会话草稿流程；此方式不验证真机摄像头与权限。
- 初次界面回归发现停止按钮被父视图的无障碍标识覆盖，移除父标识后可触达。
- 模拟器重装改变沙盒路径后，旧批次的工作区校验使列表整体失败。归档层现在跳过此类无法读取的旧批次并报告数量，不修改其文件；直接读取仍校验归属。定向归档测试覆盖新批次读取、清理及旧批次保留。
- 后续界面回归中，选图后测试报告找不到附件；界面层级显示图片实际上已加入原会话草稿，原因是测试将 SwiftUI 暴露的文本和滚动视图错误地当作 Other 类型查找。
- 最终模拟器回归：iOS 26.5 下合成画面连续采集至少三张，停止、选图并引用原图加入原会话草稿，1 项通过。此前发现采样计时和归档时间基准不一致导致第三帧触发限速、提前停止，已修正并用三帧回归覆盖。
- 真机包：Debug iOS 2.2.4 (144) 构建与签名校验通过；检查时 iPhone 显示不可连接，尚未安装，真机摄像头、权限与采样时序尚未验证。
