## 已复现的缺口

当流式控制器已存在但没有产生可合并的临时历史行，完整完成消息进入合并函数后，会走“没有行可合并”分支而不插入正文。转发 IM 在历史合并之前执行，因而可以出现 IM 有消息、TUI 与 Ctrl+T 都没有的现象。

回归测试使用现场句子，覆盖空 delta、换行、部分正文和完整正文，检查完整消息只保留一次且前后工具输出不丢。旧实现明确失败；增加完整消息插入兜底后通过。此验证证明代码缺口，并非对现场逐片段状态的补录。
