# MaiChat 网站与协议

`site/` 是部署到 `ichat.life` 的静态网站，Nginx 的网页根目录是
`/var/www/ichat`。根目录展示服务与联系渠道；`/legal/` 展示三份独立文档：

- `/legal/terms.html`：用户协议；
- `/legal/privacy.html`：隐私政策；
- `/legal/children.html`：儿童隐私保护声明。

运营主体是空熵信息技术（深圳）有限责任公司，联系邮箱是
`1925271463@kongshang.com`。当前 App 没有监护人身份和同意核验流程，因此网站
按“不满 14 周岁儿童不能独立注册”描述。若后续开放儿童账号，须先实现监护人
告知和同意，并同步更新正文。登录页和账号 API 目前均要求单独确认已年满
14 周岁，这只是用户声明，不是年龄或监护关系核验。账号服务的验证码、
失败尝试和会话记录清理规则
与隐私政策中的期限须保持一致。

依据：[个人信息保护法第十七条](https://www.spp.gov.cn/spp/fl/202108/t20210820_527244.shtml)、
[2022 年《移动互联网应用程序信息服务管理规定》](https://www.cac.gov.cn/2022-06/14/c_1656821626455324.htm)、
[《儿童个人信息网络保护规定》](https://www.cac.gov.cn/2019-08/23/c_1124913903.htm)。
协议内容应随实际服务、数据处理和运营主体联系方式变更而维护。
